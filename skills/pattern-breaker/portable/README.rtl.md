# הפרומפט הנייד

`BRIEF-PROMPT.md` הוא גרסה מרוכזת של השיטה, לכלים שלא תומכים בסקילים: Lovable, v0, Bolt, ו-Cursor rules.

**איך משתמשים:**
1. כותבים את הבריף, הקונספט ותסריט הגלילה עם הסקיל המלא ב-Claude Code. השאלון, מעבדת הקונספט ובדיקת הרפלקס קורים שם.
2. מעתיקים את כל מה שמתחת לקו המפריד ב-`BRIEF-PROMPT.md`.
3. מדביקים אותו בהודעה הראשונה לכלי, או ב-project knowledge שלו, ומתחתיו את שלושת הקבצים.
4. בסוף מצלמים ובודקים את האתר שנבנה עם הכלים של הסקיל (`scroll-film`, `motion-audit`, `gates`, `slop-scan --url`), כמו כל אתר אחר.

הפרומפט לבד לא מחליף את הסקיל. את רוב ההבדל עושים הבריף והקונספט, והפרומפט רק מוודא שהכלי יבצע אותם בנאמנות.
