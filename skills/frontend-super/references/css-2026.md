# CSS 2026 Features Reference

Modern CSS features that replace JavaScript libraries. Use these before reaching for JS.

---

## Production-Ready (Baseline — all major browsers)

### CSS Nesting

Native nesting eliminates the need for Sass/SCSS preprocessors for nesting alone.

```css
.card {
  padding: var(--space-4);
  background: var(--color-surface);

  & h3 {
    font-size: var(--text-xl);
    font-weight: 800;
  }

  & p {
    color: var(--color-text-muted);
  }

  &:hover {
    box-shadow: var(--shadow-lg);
  }

  @media (width < 768px) {
    padding: var(--space-3);
  }
}
```

### `:has()` Selector — The Parent Selector

Replaces many JavaScript conditional styling patterns. 95%+ global support.

```css
/* Style label when its input is invalid */
label:has(+ input:invalid) {
  color: var(--color-error);
}

/* Highlight card when checkbox inside is checked */
.card:has(input:checked) {
  border-color: var(--color-accent);
  background: var(--color-accent-bg);
}

/* Select previous sibling */
h2:has(+ p) {
  margin-block-end: var(--space-2);
}

/* Style table row with editable cell */
tr:has(td[contenteditable]) {
  background: var(--color-surface-elevated);
}

/* Style form when it has any error */
form:has(.error-message) {
  border-color: var(--color-error);
}

/* Responsive grid — change layout based on child count */
.grid:has(> :nth-child(4)) {
  grid-template-columns: repeat(2, 1fr);
}
```

### Container Queries

Components respond to their container size, not viewport.

```css
.card-container {
  container-type: inline-size;
  container-name: card;
}

@container card (min-width: 400px) {
  .card {
    display: grid;
    grid-template-columns: 200px 1fr;
  }
}

@container card (max-width: 399px) {
  .card {
    display: flex;
    flex-direction: column;
  }
}
```

## Progressive Enhancement (~83-85% support)

### Scroll-Driven Animations

Replace JavaScript scroll libraries (45KB+ savings) with native CSS.

**Scroll Progress Animation (e.g., reading progress bar):**

```css
.progress-bar {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 4px;
  background: var(--color-accent);
  transform-origin: left;
  animation: grow-progress linear both;
  animation-timeline: scroll();
}

@keyframes grow-progress {
  from { transform: scaleX(0); }
  to { transform: scaleX(1); }
}
```

**View-Based Animation (element appears on scroll):**

```css
.reveal-section {
  opacity: 0;
  transform: translateY(30px);
  animation: reveal linear both;
  animation-timeline: view();
  animation-range: entry 0% entry 100%;
}

@keyframes reveal {
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

**Parallax Effect:**

```css
.parallax-image {
  animation: parallax linear both;
  animation-timeline: scroll();
}

@keyframes parallax {
  from { transform: translateY(-50px); }
  to { transform: translateY(50px); }
}
```

### View Transitions API

App-like page transitions with zero JavaScript overhead.

**Same-Document Transitions (SPA):**

```javascript
document.startViewTransition(() => {
  // Update DOM here
  updateContent();
});
```

```css
::view-transition-old(root) {
  animation: fade-out 0.3s ease-in;
}

::view-transition-new(root) {
  animation: fade-in 0.3s ease-out;
}

/* Named transitions for specific elements */
.hero-image {
  view-transition-name: hero;
}

::view-transition-old(hero) {
  animation: scale-down 0.4s ease-in;
}

::view-transition-new(hero) {
  animation: scale-up 0.4s ease-out;
}
```

**Cross-Document Transitions (MPA — Astro, etc.):**

```css
@view-transition {
  navigation: auto;
}

/* Elements with matching view-transition-name across pages morph automatically */
.product-card {
  view-transition-name: product-card;
}
```

## Emerging (Interop 2026 Focus)

### Anchor Positioning

Replace 200+ lines of JavaScript tooltip/dropdown positioning with 4 lines of CSS.

```css
.trigger {
  anchor-name: --tooltip-anchor;
}

.tooltip {
  position: fixed;
  position-anchor: --tooltip-anchor;
  position-area: top center;
  position-try-fallbacks: flip-block, flip-inline;
  margin-block-end: 8px;
}
```

**Dropdown Menu:**

```css
.menu-button {
  anchor-name: --menu-anchor;
}

.dropdown-menu {
  position: fixed;
  position-anchor: --menu-anchor;
  position-area: bottom span-right;
  position-try-fallbacks: flip-block;
  width: anchor-size(width);
}
```

### `@scope`

Proximity-based styling — practical replacement for BEM naming and CSS Modules.

```css
@scope (.card) to (.card-footer) {
  /* Styles apply only inside .card but NOT inside .card-footer */
  p { color: var(--color-text); }
  a { color: var(--color-accent); }
}

@scope (.sidebar) {
  /* Styles only apply to elements inside .sidebar */
  nav { padding: var(--space-4); }
  a { font-weight: 600; }
}
```

### CSS `if()` Function

Real conditional logic inside property values — first-ever inline CSS logic.

```css
.button {
  /* Choose padding based on custom property */
  padding: if(
    style(--size: large): 16px 32px,
    style(--size: small): 8px 16px,
    12px 24px /* default */
  );
}
```

### CSS Grid Lanes (Masonry)

Native Pinterest-style layouts without JavaScript. Current syntax is **Grid Lanes**
(shipped first in Safari; experimental behind flags elsewhere — always feature-detect).
The CSSWG is also standardizing an `item-flow` shorthand on regular grid.

```css
/* Current method: Grid Lanes */
.gallery {
  display: grid-lanes;
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
  gap: var(--space-4);
}

/* Feature-detect with a column fallback */
.gallery { columns: 250px; gap: var(--space-4); }
@supports (display: grid-lanes) {
  .gallery { display: grid-lanes; grid-template-columns: repeat(auto-fill, minmax(250px, 1fr)); }
}
```

<details><summary>Old proposals (superseded — do not use)</summary>

`display: masonry` + `masonry-template-tracks`, and `grid-template-rows: masonry`,
were earlier competing proposals and never shipped broadly.

</details>

### `shape()` Function

Complex clip-path shapes using CSS units.

```css
.wave-divider {
  clip-path: shape(from 0% 100%,
    line to 0% 80%,
    curve to 50% 60% with 25% 70%,
    curve to 100% 80% with 75% 70%,
    line to 100% 100%,
    close
  );
}
```

## CSS-First Decision Matrix

| Before (JS) | After (CSS 2026) | Savings |
|---|---|---|
| `element.classList.toggle()` for conditional styles | `:has()` selector | JS eliminated |
| Scroll event listener + IntersectionObserver | `animation-timeline: view()` | 45KB+ library |
| Floating UI / Popper.js | Anchor positioning | Library eliminated |
| BEM naming / CSS Modules for scoping | `@scope` | Build step eliminated |
| Masonry.js / Isotope | Grid Lanes (`display: grid-lanes`) | Library eliminated |
| Barba.js / page transition library | View Transitions API | Library eliminated |
| JavaScript conditional property values | `if()` function | JS eliminated |

### Progressive Enhancement Pattern

```css
/* Base experience */
.element {
  opacity: 0;
  transition: opacity 0.3s ease-out;
}

.element.visible {
  opacity: 1;
}

/* Enhanced: scroll-driven animation (browsers that support it) */
@supports (animation-timeline: view()) {
  .element {
    opacity: 0;
    animation: reveal linear both;
    animation-timeline: view();
    animation-range: entry 0% entry 100%;
  }

  @keyframes reveal {
    to { opacity: 1; }
  }
}
```

## Browser Support Check

Before using any feature, verify at [caniuse.com](https://caniuse.com):
- **Baseline** (all browsers): CSS nesting, `:has()`, container queries
- **~85% support**: Scroll-driven animations, View Transitions (same-document)
- **Emerging**: Anchor positioning, `@scope`, `if()`, masonry
- Always use `@supports` for progressive enhancement on emerging features
