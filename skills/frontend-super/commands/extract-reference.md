Extract design PRINCIPLES (not exact values) from $ARGUMENTS.

## Process

1. **Fetch the URL** using WebFetch tool
2. **Analyze the design** for these dimensions:
   - **Color palette approach**: warm/cool, monochromatic/complementary, light/dark, saturation level
   - **Typography philosophy**: serif/sans, weight usage, scale feel, hierarchy approach
   - **Spacing rhythm**: tight/generous, grid feel, section breathing room
   - **Visual hierarchy strategy**: what draws the eye first, how content flows, focal points
   - **Motion approach**: subtle/dramatic, frequency, entrance patterns
   - **Layout style**: grid-based/organic, symmetric/asymmetric, contained/full-bleed

3. **Extract principles, NOT specific values**. Good: "warm monochromatic palette with a single saturated accent." Bad: "uses #FF5733 as primary color."

4. **Write to project file**: Save extracted principles to `design_principles.md` in the current project root

5. **Generate aesthetics block** suitable for CLAUDE.md

## Output Format

```markdown
# Design Principles — Extracted from [URL]
> Generated by /extract-reference on [date]

## Typography
[Approach description — font categories, not specific fonts]

## Color
[Approach description — palette strategy, not hex values]

## Spacing
[Rhythm description — tight/generous, section behavior]

## Layout
[Composition description — grid/organic, symmetry, content flow]

## Motion
[Animation approach — subtle/dramatic, entrance patterns]

## Overall Feel
[2-3 sentence summary of the design's personality]

---

## Suggested CLAUDE.md Aesthetics Block

<frontend_aesthetics>
[~100-200 token block based on extracted principles]
[Fill in specific font/color choices based on these principles]
</frontend_aesthetics>
```

6. **Tell the user**: "Principles extracted to `design_principles.md`. Copy the aesthetics block into your CLAUDE.md and fill in specific font/color choices that match these principles."
