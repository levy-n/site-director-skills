# Ethical and Legal Guidelines for Design Inspiration

## The Transformation Rule

Your work must be **transformative**. If someone sees your site and the inspiration
side by side, they should see a family resemblance at most, not a twin.

> "Take the PRINCIPLES (generous whitespace, warm palette, serif/sans pairing)
> but make the IMPLEMENTATION yours (different specific colors, different fonts,
> your own spacing scale, original layout compositions)."

---

## What Is Legal

| Action | Status |
|--------|--------|
| Studying layout structure and recreating a similar grid | LEGAL |
| Using the same color harmony (warm neutrals) with different exact values | LEGAL |
| Combining layout from Site A + colors from Site B + typography from Site C | LEGAL |
| Using the same open-source Google Font | LEGAL |
| Implementing a similar scroll animation pattern (fade-up on scroll) | LEGAL |
| Creating a similar component pattern (card with image + title + description) | LEGAL |
| Using the same general navigation pattern (sticky transparent header) | LEGAL |

## What Is Illegal

| Action | Status |
|--------|--------|
| Copying custom illustrations or photography | ILLEGAL - copyright |
| Copying source code verbatim | ILLEGAL - copyright |
| Using trademarked logos or brand assets | ILLEGAL - trademark |
| Pixel-for-pixel recreation with same colors, fonts, and content | LEGALLY RISKY |
| Copying custom icons or SVG artwork | ILLEGAL unless licensed |

## What Is Risky

| Action | Risk Level |
|--------|-----------|
| Pixel-perfect recreation of a unique single-source design | HIGH |
| Using very similar custom color combinations (exact same 5-color palette) | MEDIUM |
| Recreating a highly distinctive animation sequence | MEDIUM |
| Using same layout + same fonts + same color scheme together | HIGH |

---

## Best Practices

1. **Always combine 2+ sources** - never clone a single site
2. **Change at least 3 of these 5**: colors, fonts, layout proportions, animation style, component design
3. **Add your own creative element** - something not from any inspiration source
4. **Use your own content** - photos, copy, branding
5. **Document your sources** - know what came from where
6. **When in doubt, diverge more** - it's always safer to be more original

## The Professional Standard

Professional designers routinely study other work for inspiration. This is not only
legal but expected. The key distinction:

- **Inspiration**: Understanding WHY something works and applying those principles
- **Copying**: Reproducing WHAT something looks like without understanding why

The skill enforces inspiration-level usage by requiring:
- Multiple source analysis (never single-source cloning)
- Token extraction (understanding the system, not copying pixels)
- Design brief creation (deliberate creative decisions)
- Quality check that includes "is this transformative?" verification
