# robots.txt Template for Landing Pages

## Usage
Copy the appropriate robots.txt content into `app/robots.ts` or `public/robots.txt`.

## Next.js App Router Implementation (Recommended)

```typescript
// app/robots.ts
import { MetadataRoute } from 'next'

export default function robots(): MetadataRoute.Robots {
  const baseUrl = process.env.NEXT_PUBLIC_SITE_URL || 'https://{{DOMAIN}}'

  return {
    rules: [
      {
        // Standard search engines
        userAgent: '*',
        allow: '/',
        disallow: ['/admin/', '/api/', '/_next/'],
      },
      {
        // Allow AI search crawlers (for citation/visibility)
        userAgent: 'OAI-SearchBot',
        allow: '/',
      },
      {
        userAgent: 'ChatGPT-User',
        allow: '/',
      },
      {
        userAgent: 'PerplexityBot',
        allow: '/',
      },
      {
        // Optional: Block AI training crawlers
        userAgent: 'GPTBot',
        disallow: '/',
      },
      {
        userAgent: 'ClaudeBot',
        disallow: '/',
      },
      {
        userAgent: 'Google-Extended',
        disallow: '/',
      },
      {
        userAgent: 'CCBot',
        disallow: '/',
      },
    ],
    sitemap: `${baseUrl}/sitemap.xml`,
  }
}
```

## Static File Alternative

```
# robots.txt for {{BUSINESS_NAME}}
# Generated by MediaWave Landing Page Pipeline

# Standard crawlers
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /api/
Disallow: /_next/

# AI Search Crawlers - ALLOW (for citation/visibility)
User-agent: OAI-SearchBot
Allow: /

User-agent: ChatGPT-User
Allow: /

User-agent: PerplexityBot
Allow: /

# AI Training Crawlers - BLOCK (optional)
User-agent: GPTBot
Disallow: /

User-agent: ClaudeBot
Disallow: /

User-agent: Google-Extended
Disallow: /

User-agent: CCBot
Disallow: /

# Sitemap
Sitemap: https://{{DOMAIN}}/sitemap.xml
```

## Placeholder Values

| Placeholder | Description | Example |
|------------|-------------|---------|
| `{{DOMAIN}}` | Site domain | `bakery-rehovot.co.il` |
| `{{BUSINESS_NAME}}` | Business name | `מאפיית הלחם של רחובות` |

## Important Notes

- **AI Search vs AI Training**: `OAI-SearchBot` and `ChatGPT-User` are for real-time search (ALLOW). `GPTBot` is for training data (optionally BLOCK).
- **PerplexityBot** handles both indexing and retrieval - ALLOW it.
- **Test after deployment**: Visit `https://yourdomain.co.il/robots.txt` to verify.
- **Vercel note**: Vercel respects robots.txt from both `app/robots.ts` and `public/robots.txt`. The App Router method is preferred.
